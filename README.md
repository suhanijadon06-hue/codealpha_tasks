# CodeAlpha Python Programming Tasks

Tasks completed as part of the **CodeAlpha Python Programming Internship**.

| Task | Project | Description |
|---|---|---|
| 1 | [Hangman Game](Task1_HangmanGame/) | Text-based Hangman with difficulty levels, hints and scoring |
| 2 | [Stock Portfolio Tracker](Task2_StockPortfolioTracker/) | Menu-driven portfolio tracker with buy/sell, profit/loss and CSV/TXT export |
| 4 | [Basic Chatbot](Task4_BasicChatbot/) | Rule-based chatbot with intent matching, name memory, calculator and chat log |

## How to Run
All projects use Python 3 and only the standard library, so there's nothing to install.

```bash
cd Task1_HangmanGame && python hangman.py
cd Task2_StockPortfolioTracker && python portfolio.py
cd Task4_BasicChatbot && python chatbot.py
```

See the README inside each folder for features and example output.
